Detached signature and official release public key are included. Signature verified against fingerprint FCF986EA15E6E293A5644F10B4322F04D67658D8.
No FFmpeg source-code modifications were made. Configuration/header files generated by configure are build outputs, not source patches.

Build tools: Microsoft Visual C++ 14.44.35207 x64, Windows SDK, GNU make/MSYS2, NASM 3.01. NASM portable ZIP SHA256: E0BA5157007ABC7B1A65118A96657A961DDF55F7E3F632EE035366DFCE039CA4 (official HTTPS download; not independently signature-verified).
Use an x64 Visual Studio developer environment, with NASM/compiler/Windows SDK tools in the MSYS2 shell PATH. The build used a temporary Windows SUBST drive pointing only at its workspace output folder (removed afterward), with the source under Z:\source. This keeps compiler-generated assertion paths anonymous without disabling assertions or editing FFmpeg. Map a currently unused drive to your staging directory, extract the archive into its source subfolder, and run there. Keep relative include paths from being expanded unnecessarily:

export MSYS2_ARG_CONV_EXCL='-I'

./configure --toolchain=msvc --arch=x86_64 --target-os=win64 --prefix=/ffmpeg-lgpl --enable-shared --disable-static --disable-gpl --disable-nonfree --disable-version3 --disable-autodetect --disable-programs --disable-doc --disable-debug --disable-network --disable-everything --enable-avcodec --enable-avutil --enable-swscale --disable-avformat --disable-avdevice --disable-avfilter --disable-swresample --disable-postproc --enable-decoder=h264 --enable-parser=h264 --enable-w32threads --extra-cflags=-MT
make -r -j4
make -r DESTDIR=YOUR_STAGING_DIRECTORY install

This configuration builds avcodec-61.dll, avutil-59.dll and swscale-8.dll. The production app ships only avcodec-61.dll and avutil-59.dll; the unused developer-preview scaler is omitted. Standalone x86 assembly and runtime CPU detection are enabled. No external codec libraries, GPL, version3 or nonfree features are enabled.
